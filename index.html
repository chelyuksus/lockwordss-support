Lockwordss — Поддержка

Черновик. Не для App Store Connect.

Страница подготовлена, но ещё не сверена с исходным кодом версии 1.1 (сборка 5). Это не опубликованная официальная политика или подтверждённая инструкция. GitHub Pages пока не включён.

Локальный менеджер учётных записей и паролей для iPhone. Ниже подготовлены ответы для будущей страницы поддержки.

Начало работы

Как добавить учётную запись

Откройте список записей и форму добавления. Укажите название сервиса, заполните нужные поля и нажмите «Сохранить».

Как изменить или удалить запись

Откройте запись и выберите «Редактировать». После изменения нажмите «Сохранить». Для удаления используйте «Удалить запись» и подтвердите действие. Перед удалением убедитесь, что данные больше не нужны.

Как использовать Face ID

Настройте Face ID и код-пароль в настройках iPhone. При запросе приложения подтвердите личность системным способом. В базовой реализации параметры блокировки доступны в настройках приложения; названия и поведение текущей сборки ещё проверяются.

Как сгенерировать пароль

В редакторе записи выберите «Сгенерировать пароль», затем сохраните запись. Это создаёт значение в приложении, но не меняет пароль на сайте сервиса: смену пароля нужно выполнить отдельно на самом сайте.

Как добавлять изображения

В текущем описании приложения предусмотрены изображения и зашифрованные вложения. Точные шаги выбора фото или камеры будут добавлены после проверки актуального редактора. Не используйте изображения с чужими личными данными без разрешения.

Хранение и обновление

По описанию текущей версии пароли хранятся в Apple Keychain, сведения о записях — в SwiftData, вложения — локально в зашифрованном виде. Независимый сервер синхронизации паролей не предусмотрен. Возможность восстановления на другом устройстве не подтверждена.

Для версии, установленной из App Store, проверяйте обновления в App Store. Если приложение установлено через TestFlight, используйте TestFlight. Не удаляйте приложение ради обновления или исправления ошибки.

Частые вопросы

Почему иконка сервиса не появилась?

Получение иконок зависит от интернета и внешних источников. Отсутствующая или устаревшая иконка не означает, что сохранённый пароль неверен. Точные источники и настройки поиска текущей сборки ещё проверяются.

Можно ли восстановить забытый пароль через поддержку?

Не отправляйте пароль в поддержку. Для восстановления доступа к стороннему сервису используйте его официальную процедуру. Возможность восстановления локального хранилища приложения должна быть проверена отдельно.

Можно ли удалить и установить приложение заново?

Переустановка может привести к потере данных или недоступности зашифрованных вложений. Не полагайтесь на неё как на способ исправления ошибки или резервирования.

Связаться по вопросу приложения

Публичные обращения на GitHub

GitHub Issues — публичный, не конфиденциальный канал. Для отправки обращения может потребоваться аккаунт GitHub. Пишите только версию приложения, версию iOS и шаги воспроизведения на вымышленных данных.

Не публикуйте пароли, коды восстановления, имена учётных записей, личные данные, содержимое хранилища или скриншоты с секретами. Для сообщения, требующего личных данных, дождитесь отдельного приватного контакта. Email поддержки ещё не назначен; достаточность одного Issues для требований Apple не подтверждена.
